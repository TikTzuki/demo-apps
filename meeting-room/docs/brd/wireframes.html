How screens connect to each other

    |
    |--- tap org card ---> [Screen 2: Org Detail / Room List]
    |                           |
    |                           |--- tap room ---> [Screen 3: Room Weekly Calendar]
    |                           |                        |
    |                           |                        |--- tap ←/→ ---> prev/next week
    |                           |                        |--- tap day ---> [Screen 3b: shows that day's schedule]
    |                           |                        |--- submit form ---> [Screen 4: Confirmation]
    |                           |                                                    |
    |                           |<-------------- "Back to Rooms" --------------------|
    |                           |
    |                           |--- tap + FAB (admin) ---> [Screen 7: Create Room]
    |                           |                                  |
    |                           |<-------------- create success ---|
    |
    |--- tap gear icon ---> [Screen 5: Admin Secret Modal]
                                |
